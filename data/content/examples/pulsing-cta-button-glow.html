Conversion Psychology & Ambient Motion

Subtle motion draws peripheral vision. By restricting the amplitude of motion to under 8% scale, the CTA feels alive without appearing distracting or annoying to visitors reviewing pricing tables or feature lists.

CSS Expansion Rings

By animating a pseudo-element or layered shadow ring from opacity 0.8 down to 0 while scaling outward, we create a sonar ripple effect without JavaScript listeners. 

@keyframes looply-cta-ripple {
  0%   { transform: scale(0.95); opacity: 0.8; }
  70%  { transform: scale(1.35); opacity: 0; }
  100% { transform: scale(1.35); opacity: 0; }
}
