Orchestrating Staggered Hero Delays

When displaying multiple product screenshots or UI cards, animating them simultaneously can feel jarring. Adding a 0.2s delay between layer entries guides the viewer's eye naturally across your interface.

Managing Fill Mode and Initial States

Looply exports CSS with animation-fill-mode: forwards and sets initial 0% keyframe opacities, ensuring that cards do not flicker before their entrance delays complete. 

.card-center {
  animation: looply-hero-slide 1.2s cubic-bezier(0.16, 1, 0.3, 1) 0.1s both;
}
.card-left {
  animation: looply-hero-slide 1.2s cubic-bezier(0.16, 1, 0.3, 1) 0.3s both;
}
.card-right {
  animation: looply-hero-slide 1.2s cubic-bezier(0.16, 1, 0.3, 1) 0.5s both;
}
