Why Micro-Interactions Convert

Badges and floating feature highlights attract user attention without obstructing reading flow. By staggering the timing between the central icon and outer halo, we produce an organic, breathing effect that signals interactability.

Layer Orchestration & Physics

This example uses 2 layers: a background radial gradient halo and the foreground badge icon. The halo scales between 0.85 and 1.2 at a 3-second cycle, while the badge glides up 15px with an ease-in-out easing.

Production CSS Keyframe Code

Exported from Looply, this snippet uses GPU-accelerated transform: translate3d and executes smoothly at 60 FPS across all browsers. 

@keyframes looply-anim-halo {

  100% { transform: translate3d(200px, 100px, 0) scale(0.85); opacity: 0.3; }
