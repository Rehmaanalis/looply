The Dual Mode Architecture: Accessible & Uncompromising

Not every animation requires manual keyframing from scratch. In Simple Mode, creators select a layer, pick an entrance or motion preset (like Elastic Bounce, Pulse, or Floating), customize the duration pill, and preview immediately. For motion designers and engineers who demand precision, Advanced Mode unlocks individual property tracks, custom cubic-bezier curves, and physical springs.

This bifurcation ensures that product managers or marketers can rapidly construct branded animated illustrations in seconds, while senior frontend engineers can dial in easing curves down to millisecond increments.

Bringing React Native Reanimated Concepts to the Browser

Inspired by React Native Reanimated, Looply now features a full damped harmonic oscillator spring solver. Creators can specify mass (m), stiffness (k), and damping (c), and preview the settling curve in real time. 

// Physical harmonic oscillator equations evaluated at 24 discrete intervals

Seamless Multi-Layer Staggering

Choreographing multiple layers used to require tedious manual delay calculations. The new Stagger tool distributes step delays across all selected layers with a single click, supporting both top-to-bottom and bottom-to-top z-index ordering.

  • Consistent timing increments: Apply 50ms, 100ms, or 200ms step offsets across multiple layers simultaneously.
  • Automatic clip window bounds: Layers respect in-point and out-point clipping without sudden flashes or layout jumps.
  • Dual-target code generation: Works identically whether exporting standalone CSS or React Native Reanimated components.
